# ☕ Exercícios de POO em Java

Repositório com exercícios desenvolvidos durante as aulas de
Programação Orientada a Objetos (POO), utilizando Java.

## 📚 Conteúdos praticados

- Classes e objetos
- Instanciação de objetos
- Atributos e métodos
- Herança
- Uso de `this`
- Relação entre classes

## 🎯 Objetivo

Praticar os conceitos fundamentais de Programação Orientada a Objetos
por meio de exercícios e pequenas aplicações desenvolvidas durante a
graduação em Análise e Desenvolvimento de Sistemas.

## 🛠️ Tecnologia

- Java

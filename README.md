# 📚 Exercícios e Projetos - ADS

Repositório criado para reunir exercícios, atividades e projetos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas**.

Os conteúdos foram desenvolvidos principalmente durante as disciplinas de **Programação Orientada a Objetos (POO), Desenvolvimento Web e Flutter**, registrando parte da minha evolução acadêmica e prática em programação.

## 📂 Conteúdos

### ☕ Programação Orientada a Objetos (POO)

Exercícios desenvolvidos durante as aulas de Programação Orientada a Objetos, utilizando Java.

Os exercícios abordam principalmente:

- Herança
- Uso de `this`
- Classes
- Atributos e métodos

**Tecnologia:** Java

### 🌐 Desenvolvimento Web

Exercícios e atividades desenvolvidos durante as aulas de Desenvolvimento Web.

**Tecnologias utilizadas:**

- HTML
- CSS
- JavaScript

### 📱 Flutter

Exercícios e atividades desenvolvidos durante as aulas de Flutter, com foco na criação de interfaces e aplicações.

**Tecnologias utilizadas:**

- Dart
- Flutter

## 🎯 Objetivo

Este repositório reúne parte dos exercícios e atividades realizados durante a graduação, servindo como registro do aprendizado e da evolução no desenvolvimento de software.

Os conteúdos representam diferentes etapas da formação acadêmica, envolvendo programação, desenvolvimento Web e criação de aplicações com Flutter.
